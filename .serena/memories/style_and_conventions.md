# Style and Conventions: Mastodon

## Coding Guidelines
- **Ruby**: Follow standard Rails conventions and RuboCop rules.
- **JavaScript/TypeScript**: Follow ESLint rules and use modern React patterns.
- **API**: Changes/additions must follow the API documentation standards.
- **I18n**: All user-facing strings should be localized using the i18n-tasks workflow.

## Naming Conventions
- Ruby files/classes follow standard Rails snake_case/PascalCase.
- Frontend components follow PascalCase for JSX/TSX files.

## Testing Guidelines
- Ruby code must have accompanying RSpec tests.
- Frontend code should have Vitest unit tests.
