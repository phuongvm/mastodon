# Product Overview: Mastodon

Mastodon is a free, open-source social network server based on ActivityPub, where users can follow friends and discover new ones. It is part of the federated network known as the Fediverse.

## Tech Stack
- **Back-end**: Ruby on Rails
- **Front-end**: React, TypeScript, SCSS
- **Storage**: PostgreSQL, Redis
- **Tooling**: Yarn (v4), Vite, Vitest, RSpec
- **Deployment**: Docker, Docker Compose, Vagrant, Helm
